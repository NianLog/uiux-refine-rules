# 内容区平滑展开

## 适用条件

内容高度不固定的折叠区、解释区或思考面板。

## 排除条件

已经有成熟折叠组件时优先使用它；目标浏览器不支持相应动画时直接切换状态。

## 规则

可用外层 grid-template-rows 从 0fr 到 1fr，内层 min-height: 0 和 overflow: hidden。触发按钮维护 aria-expanded 和 aria-controls；折叠内容不能继续被 Tab 进入。先移走内部焦点再折叠，并按动画阶段处理 inert/hidden，不靠透明度假装隐藏。

## 参数

时长沿用项目展开动效 token，减少动态效果时直接切换。默认不以 JavaScript 测量高度。

## 验收

检查空内容、长内容、图片延迟加载和快速反复展开；折叠后没有隐藏焦点或可点击区域。

## 反例

grid 行变成 0fr，但内容仍有默认最小高度，内部输入框仍可被 Tab 聚焦。
